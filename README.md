## 🎯 Purpose

After mastering vanilla JavaScript, this is where I started learning **React.js** — understanding how modern frontend frameworks work through component-based architecture.

## 🧩 Components Built

| Component | What It Does |
|-----------|-------------|
| `Navbar` | Navigation bar — React component with links and layout |
| `Cards` | Reusable card component — props-driven dynamic content |
| `Contact` | Contact form — controlled inputs with React state |
| `Footer` | Footer component — reusable across pages |
| `APIComponent` | Fetches and displays live data from an external API |

## 💡 What I Learned

**React Core Concepts:**
- What components are and why they make UI reusable
- JSX syntax — writing HTML inside JavaScript
- `props` — passing data from parent to child components
- `useState` — managing local component state
- `useEffect` — running side effects (API calls on mount)

**Component Architecture:**
- Breaking a UI into small, reusable pieces
- Parent → child data flow with props
- How React re-renders when state changes

**API Integration in React:**
- Fetching data with `useEffect` + `fetch()`
- Storing API response in `useState`
- Rendering dynamic data from an API inside JSX

**Forms in React:**
- Controlled inputs — `value` + `onChange`
- Managing form state with `useState`
- Handling form submission in React
